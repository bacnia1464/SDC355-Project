# Bachir's Portfolio Project

## Overview
This repository contains a personal portfolio webpage. The page demonstrates modern web development practices including structural design, interactive logic, and dynamic data rendering.

### Languages and Technologies Used
*   **HTML5:** Used for semantic page structure, accessible forms, and content organization.
*   **CSS3:** Implemented for base styling, layout spacing, responsive transitions, and visual themes (including Dark Mode).
*   **Vanilla JavaScript (ES6+):** Utilized for DOM manipulation, control flow logic, event handling, asynchronous timing functions (`setTimeout`), and managing browser storage. 

## Dependencies & Running the Project
This project is built entirely with fundamental web technologies and does not rely on external frameworks, libraries, or package managers such as Node.js, React, or Bootstrap. 

*   **Dependencies:** None required.
*   **Browser Storage:** The application utilizes native Web APIs (`localStorage` for theme persistence and `sessionStorage` for dynamic project rendering). Ensure your browser allows local data storage for full functionality.

**To view the project:**
Simply clone or download this repository and open `index.html` in any modern web browser.
